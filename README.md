## 課程重點
- 活用 Command / Skill，建立最佳且符合團隊規範的開發流程
- Context 聚焦與 CLAUDE.md：使用時機 vs. 最佳實踐
- 企業 Legacy System 的切入點與導入策略
- 重新定義 AI 時代的 SDLC 軟體開發
- 以 Skills 定義系統開發與設計的標準流程

## 部署方式
push 到 `main` 且 `src/**` 有變動時，GitHub Actions 會先檢查必要檔案與本機連結，通過後自動發佈 `src/` 到 GitHub Pages，約 1 分鐘上線。Pull Request 只做檢查，不會發佈。

詳細說明請見 [GitHub_Page_Workflow_README.md](GitHub_Page_Workflow_README.md)。
